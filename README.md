# 外空治理困境：一场无声的圈地运动

一个关于太空治理与近地轨道资源争夺的互动信息页面。

## 在线访问

**Vercel 部署地址**：https://your-project.vercel.app

**GitHub 仓库**：https://github.com/YOUR_USERNAME/space-governance

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- 无框架依赖
- 部署平台：Vercel

## 本地开发

直接用浏览器打开 `外空治理困境：一场无声的圈地运动.html` 即可。

## 部署说明

本项目部署在 Vercel，使用 GitHub 作为代码托管。

### 手动部署步骤

1. 将本项目推送到 GitHub 仓库
2. 访问 [vercel.com](https://vercel.com)
3. 使用 GitHub 账号登录
4. 点击 "New Project" → "Import Git Repository"
5. 选择你的仓库
6. Framework Preset 选择 "Other"
7. 点击 Deploy

### 自动化部署（推荐）

通过 Vercel CLI 部署：

```bash
npm i -g vercel
vercel login
vercel
```

## 内容许可

本页面内容基于联合国和平利用外层空间委员会（COPUOS）公开文件、国际宇航科学院（IAA）太空交通管理报告等公开资料编写。
